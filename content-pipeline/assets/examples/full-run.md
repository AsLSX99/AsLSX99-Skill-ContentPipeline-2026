# 完整跑通示例：一天的流水线

> 领域设定：AI 工具｜平台：公众号｜字数 2500｜日更｜触发 08:30｜通知：QQ 邮箱｜编排模式 A（初稿后暂停等人改稿）

## Spec 摘要

- 领域：AI 工具｜读者：想用 AI 提效但被流程卡住的职场人
- 口吻：用 AI 三年的老手跟朋友聊天，年限=5
- 信源：知乎、微信搜一搜、新闻热点｜N=5｜权重：痛点40%+差异化30%+素材30%
- 知识库：资料库（全文检索，不分类）｜配比：观点3/数据2/案例2
- Style Profile：默认档案（段间空行/小标题加粗/金句成行加粗/删光 Markdown 符号）
- 通知：QQ 邮箱，标题带选题名

## 08:30 自动执行记录

### ① 选题（P1 → G1）

产出表格 5 条，节选第 1 条：

| 排名 | 一句话角度 | 目标读者痛点 | 差异化切入点 | 难度 | 素材 |
|------|-----------|-------------|-------------|------|------|
| 1 | AI 写周报越写越假：3 个把周报写出人味的提示词结构 | 周报每周一写两小时，还被老板说"看不出你干了啥" | 不讲"用 AI 提效"，讲"AI 味"的成因与解法 | 2 | 4 |

- G1：5 条 ✓｜5 字段齐全 ✓｜角度非话题词 ✓｜降序 ✓ → **通过**，人工 3 分钟挑定第 1 条为今日主选题

### ② 素材（P2 → G2）

- 观点 3 条（来源：资料库《提示词结构化实践.md》第 2 节 等）✓
- 数据 2 条（含数值+口径+时间：如"测试 12 篇周报，结构化提示词组返工率 17%，自由发挥组 63%（2026-03 内部样本）"）✓
- 案例 2 个（主体/动作/结果齐全）✓
- 来源标注率 100% ✓ → **G2 通过**，无缺口

### ③ 初稿（P3 → G3.5）

- 生成初稿 2480 字、3 节、标题备选 3 个，附改稿清单（自评 AI 腔 5 句 + 3 处建议换真实经历）
- G3 机器断言：禁词 0 ✓｜开头无套话 ✓｜字数 2480 ∈ [2250,2750] ✓｜小节 3 ✓ → **机器通过**
- **流水线暂停，通知人改稿（模式 A）**
- 人工 18 分钟：删 4 句机器味表达、在第 1 节换入"上周帮同事改周报被回了句'这像你写的？'"、砍 6 个长句 → 改稿清单完成 ✓

### ④ 排版（P4 → G4）

- 按默认档案输出 HTML 预览 + 纯文本
- G4：Markdown 残留 0 ✓｜段间空行 ✓｜金句 3 处成行加粗 ✓｜HTML 可打开 ✓ → **通过**

### ⑤ 分发（P5）

发送至 QQ 邮箱，标题：

```
【日更】稿件出炉：AI 写周报越写越假：3 个把周报写出人味的提示词结构
字数 2480｜小节 3｜门禁 G1✓ G2✓ G3✓ G4✓（缺口：无）
成品：附件 HTML + 纯文本
待完成：审稿 → 改稿清单复核 → 发布
```

人：手机收信 → 审稿 3 分钟 → 手机预览扫一遍 → 后台粘贴 → 11:00 发布。

## 时间对账（本示例实测口径）

| 环节 | 基线 | 本例 |
|------|------|------|
| 找选题 | 60 min | 0 + 3 min（挑） |
| 找素材 | 40 min | 0 |
| 写初稿 | 90 min | 18 min（改） |
| 排版 | 30 min | 1 min |
| 合计（不含人工审稿发布） | ~3.7 h | ~22 min |

## 发布后回填（48h）

阅读/在看/评论写入 08 回流表 → 标签"周报/提示词结构" → 样本 ≥10 篇前只记录不调权。
