# 参数化提示词库（Prompt Pack v1.0）

> 所有占位符 `【{...}】` 从 `pipeline-spec.md` 取值。直接改参数复用，不要改结构。

## P1 选题（G1 前置）

```
搜索【{领域}】最近24小时的热门话题，信源：【{信源列表}】。
给出 {N=5} 个选题，每个选题包含：
1. 一句话角度（切入方向，不是话题词）
2. 目标读者痛点（谁、在什么场景下被什么问题卡住）
3. 差异化切入点（与现有爆款的区别）
4. 预估写作难度 1–5
5. 素材可得性 1–5
输出为表格，按 痛点强度40% + 差异化30% + 素材可得性30% 降序排列。
难度>4 且素材可得性<2 的条目标注"需外部素材"。
```

## P2 素材（G2 前置）

```
确认今日选题：【{主选题}】。从资料库检索相关素材，整理为结构化素材摘要：
- 可引用观点 {N1=3} 条、可用数据 {N2=2} 条、相关案例 {N3=2} 个
- 每条注明来源：资料库文件名 + 章节/页码（尽量）
- 弱相关素材不要凑数，宁缺毋滥
- 数据必须含数值、口径、时间范围
按"观点 / 数据 / 案例"三板块输出；不足的板块标注 ⚠ 缺口。
```

## P3 初稿（G3 前置）

```
基于选题【{主选题}】与素材摘要，写一篇{平台}文章初稿：
1. 标题 {NT=3} 个备选：有点击欲、不做标题党
2. 开头用具体场景或故事切入，禁止"在这个……的时代"
3. 正文约 {字数=2500} 字，分 {小节数=3} 节，每节一个小标题
4. 口吻：像在{领域}干了 {年限=5} 年的老手在跟朋友聊天
5. 观点/数据/案例优先用素材摘要，使用处标来源
6. ⚠ 缺口位置保留占位，不编造
7. 结尾留一个引导评论的问题
输出后附【改稿清单】：自评最像 AI 腔的 5 句 + 建议替换真实经历的位置。
```

## P4 排版（G4 前置）

```
把改定稿转换成{平台}可用排版，严格按 Style Profile：
段落之间空一行、小标题加粗、金句单独成行并加粗、
删除所有 Markdown 符号，生成排版好的 HTML 预览页，
同时给出纯文本版。
```

## P5 分发

```
【{频次}】稿件出炉：{主选题}
字数 {字数}｜小节 {小节数}｜门禁 G1✓ G2✓ G3✓ G4✓（缺口：{无/N处}）
成品：{链接或附件}（HTML + 纯文本）
待完成：审稿 → 改稿清单复核 → 发布
```
