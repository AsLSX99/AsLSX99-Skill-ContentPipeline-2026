# 流水线配置表（Pipeline Spec）

> 总配置。所有提示词、门禁、通知从这里取值。填完此表再逐环节落地。

```markdown
## Pipeline Spec v1.0
### 定位
- 领域：【必填，如：职场效率 / AI 工具 / 编程实战】
- 目标读者：【一句话：谁 + 什么场景 + 什么痛点】
- 口吻基准：【如：行业老手聊天感；年限=5】
### 发布参数
- 平台：【公众号 / 知乎 / 博客 / Newsletter / 小红书】
- 字数：【默认 2500】
- 小节数：【默认 3】
- 频次：【日更 / 隔日 / 每周 N】
- 触发时间：【默认 08:30】
- 发布时间：【如：上午 11:00】
### 选题参数
- 信源列表：【默认：知乎、微信搜一搜、新闻热点】
- 每日选题数 N：【默认 5】
- 评分权重：【默认 痛点40% + 差异化30% + 素材可得性30%】
- 选题 Skill：【有则写名称并加载，无则留空】
### 素材参数
- 知识库位置：【平台资料库 / 本地目录路径】
- 素材配比：【观点3 / 数据2 / 案例2】
- 清理周期：【每月 1 次】
### 排版参数
- Style Profile：【有旧文档案写路径；无则用"默认"】
- 默认档案：段间空行 / 小标题加粗 / 金句成行加粗 / 删光 Markdown 符号
### 分发参数
- 通知方式：【邮件 / 即时消息 / 文件目录 / 会话内】
- 通知地址：【如 xxx@qq.com】
### 执行编排
- 模式：【A：初稿后暂停等人改稿（推荐）/ B：一口气跑完】
- 平台接线：【按 07 文档接线表填写 C1–C5 实际工具】
### 门禁状态（运行后回填）
- G1 选题：[ ] 通过 / 打回 [N] 次
- G2 素材：[ ] 通过 / 缺口 [N] 处
- G3 初稿：[ ] 机器通过 → 人工改稿 [ ] 完成
- G4 成品：[ ] 通过
```

## 依赖关系（编排时按此传递上下文）

```
Spec → 01(取领域/信源/N) → 今日主选题
主选题 → 02(取知识库/配比) → 素材摘要 + 缺口清单
主选题 + 摘要 + 缺口 → 03(取字数/小节/口吻) → 初稿 + 改稿清单
改定稿 + Style Profile → 04 → 成品(HTML + 纯文本)
成品 + 门禁结果 + 缺口 → 05(取通知方式/地址) → 交付通知
发布数据 → 08 回流表 → 更新 01 权重
```

**传递铁律**：主选题、缺口清单、门禁结果三个变量必须逐环携带，任何一环吞掉它们即视为编排失败。
