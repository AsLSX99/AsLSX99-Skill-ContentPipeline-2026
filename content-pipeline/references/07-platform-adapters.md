# 07 平台适配：五能力模型，接线到任何 Agent

> 流水线不绑定任何具体产品。把它跑起来只需要五个能力，任何 Agent 只要能提供这五个能力（或其中带人工触发的子集），就能完整承接。

## 五能力模型

| 能力 | 流水线用途 | 缺失时的降级 |
|------|-----------|-------------|
| C1 定时触发 | 每天 8:30 自动跑选题与后续环节 | 人手动发起（每天一句话触发） |
| C2 知识库检索 | 资料库全文检索，素材摘要的来源 | 本地文件夹 + 关键词搜索；或直接粘贴素材 |
| C3 对话生成 | 五条参数化提示词的执行 | （核心能力，无降级——没有它就不是流水线） |
| C4 文件读写 | 输出 HTML/纯文本成品、存档、PENDING 队列 | 会话内直接输出成品文本 |
| C5 通知投递 | 交付提醒（邮件/消息/目录） | 会话内交付；或 C1 触发时人工查看 |

**最小可运行集**：C3 + 人工触发。其余能力决定"自动化程度"，不决定"能不能跑"。

## 接线表

| 能力 | 带自动化任务的平台（WorkBuddy 类） | 代码执行型 Agent（Claude Code 类） | 纯对话 Agent |
|------|-----------------------------------|-----------------------------------|-------------|
| C1 | 平台的"自动化/定时任务"入口，设 8:30 | 系统 cron / 调度器调用 `pipeline run --step all` | 用户每天一句话触发 |
| C2 | 平台"资料库"功能（存时不管分类，靠全文检索） | 本地 `notes/` 目录 + grep/向量检索 | 粘贴素材或上传文件 |
| C3 | 对话框直接执行 | 同左 | 同左 |
| C4 | 平台文件输出 | 写入 `output/YYYY-MM-DD-*.md` + HTML | 会话内输出 |
| C5 | 平台连接器（邮箱/企微等，授权一次） | `sendmail` / webhook / Bot API | 会话内交付 |

### 典型接线示例（三步）

1. **定时**：在运行环境新建定时任务，时间 {触发时间=08:30}，内容为 `pipeline run --step all`（或直接粘贴第 1 步选题提示词，任务里串接后续）
2. **知识库**：把资料库指向 {知识库位置}；没有资料库功能就指定一个文件夹
3. **通知**：连接 {通知方式}（授权一次），任务末尾加"完成后把最终稿发送到 {地址}"

### 逐环节任务串接（自动化模式）

定时任务里按顺序执行，上一环输出传给下一环（同一会话或显式传递变量）：

```
run 01-topic → 取第1条为今日主选题 → run 02-research → run 03-drafting
→ 人工改稿（异步，人收到初稿后执行）→ run 04-formatting → run 05-distribution
```

注意：**改稿是异步人工环节**，两种编排方式选一：

- A（推荐）：初稿生成后暂停并通知，人改完发"改完了"，流水线续跑 04/05
- B：流水线一口气跑完 04/05，人改稿后在发布前手动重新排版一次

## 选题类 Skill 加载（可选增强）

运行环境若有选题/热点类 Skill，在 C3 执行 01 之前加载（安装方式遵循各平台的 Skill 管理机制，通常可让 Agent 自行搜索安装）。没有则用 01 的参数化提示词直接跑，收窄信源可弥补。

## 无代码环境的最小配置清单

- [ ] 一个能定时/或每天手动发起的入口
- [ ] 一个能全文搜索的素材存放处（文件夹也行）
- [ ] 五条提示词（见 prompt-pack）存成可一键粘贴的片段
- [ ] 一个能收到成品的地方（会话/文件夹/邮箱）
- [ ] 改稿清单打印件或置顶笔记
