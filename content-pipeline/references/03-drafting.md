# 03 初稿环节：骨架 + 毛坯，人做装修

> 产出：初稿（3 备选标题 / 场景开头 / 分节正文）+ 改稿清单 + 初稿门禁 G3。痛点基线：人工写约 90 分钟，自动化后 20 分钟（只改不写）。

## 红线：AI 初稿不能直接发

直接发的稿子一股机器味，读者一眼就跑。流水线的定位是让它出**骨架+毛坯**，人做最后的**装修**。这 15–20 分钟省不掉，也不该省——流水线干掉的是体力活，判断力和个人风格必须是自己的。

## 参数化提示词

```
基于今日选题【{主选题}】和素材摘要，写一篇{平台}文章初稿。要求：
1. 标题 {NT=3} 个备选：有点击欲但不做标题党（不含"震惊/99%的人不知道"类词）
2. 开头用一个具体场景或故事切入，禁止"在这个……的时代"式开头
3. 正文约 {字数=2500} 字，分 {小节数=3} 节，每节一个小标题
4. 口吻：像一个在{领域}干了 {年限=5} 年的老手在跟朋友聊天
5. 素材摘要中的观点/数据/案例优先使用，使用处标注来源
6. 标注了"⚠ 缺口"的位置保留占位，不编造内容
7. 结尾留一个引导评论的问题
输出后附【改稿清单】：机器自评最像 AI 腔的 5 句 + 建议替换的真实经历位置。
```

### 关键参数

| 参数 | 默认 | 说明 |
|------|------|------|
| {NT} | 3 | 标题备选数 |
| {字数} | 2500 | 按平台改（知乎 3000+，小红书 800） |
| {小节数} | 3 | 2500 字对应 3 节，每节 700–900 字 |
| {年限} | 5 | 口吻强度参数，越大越"老手" |

## 改稿清单（人工 15–20 分钟，只做三件事）

1. **删 AI 腔**：命中禁词表的句子整句重写（禁词表见 G3）
2. **换真实经历**：在初稿标注的 3–5 个位置插入自己的案例、数字、翻车故事——**这是全文最不能省的一步**，机器味的解药不是文采是具体
3. **砍长句**：超过 40 字的句子一律拆短

改完顺手核对：标题与内容是否兑现、开头 3 行够不够抓人、结尾问题是否真的想让人回答。

## G3 初稿门禁（机器可判 + 人工判）

**机器可判：**

- [ ] 标题备选 = {NT} 个，禁词命中 0
- [ ] 开头 100 字内无"在这个……的时代"
- [ ] 字数在 {字数} ±10% 区间
- [ ] 小节数 = {小节数}，每节有小标题
- [ ] 素材使用处来源标注齐全
- [ ] ⚠ 缺口占位未被编造内容填充
- [ ] 禁词表命中数 = 0：`总而言之 / 赋能 / 抓手 / 闭环 / 底层逻辑 / 深度解析 / 值得深思 / 不难发现 / 综上所述 / 首先其次最后`（命中即打回）

**人工判（改稿时完成）：**

- [ ] 至少 3 处真实个人经历
- [ ] 口吻像本人在聊天（读出声不别扭）
- [ ] 每节有可执行的"带走的东西"（方法/清单/判断标准）

## 失败回退

- 素材缺口导致某节空洞 → 保留占位 + 在改稿清单置顶标注"待补素材"
- 两轮生成仍 AI 腔严重 → 降级要求：只保留结构与论点，人重写开头和每节首段（这比反复重跑省时间）

## 时间账

| 项 | 以前 | 现在 |
|----|------|------|
| 写初稿 | 90 分钟 | 20 分钟（只改不写） |
