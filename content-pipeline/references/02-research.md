# 02 素材环节：自动归集到资料库并结构化

> 产出：结构化素材摘要（观点/数据/案例，每条带来源）+ 素材门禁 G2。痛点基线：人工翻素材约 40 分钟，自动化后 0 分钟。

## 核心设计：平时随手存，用的时候自动调

资料库的价值不在"存"而在**全文检索**——存的时候不用分类，写的时候靠检索召回。维护一个不分类但可检索的库，比维护一套分类体系的存活率高得多（分类体系必然荒废）。

### 入库规范（三条，多了守不住）

1. **原样存**：文章/报告/案例整篇存入，保留标题与出处 URL
2. **随手存**：看到就存，不判断"以后用不用得上"
3. **定期清理**：每月删一次纯标题党与重复转载（检索噪音直接降低摘要质量）

## 参数化提示词

```
确认今日选题：【{主选题}】（来自选题环节输出；如另有指定则以指定为准）。
从资料库检索与该选题相关的素材，整理为结构化素材摘要：
- 板块：可引用观点 {N1=3} 条、可用数据 {N2=2} 条、相关案例 {N3=2} 个
- 每条必须注明来源：资料库文件名 + 尽量标注章节/页码
- 与选题弱相关的素材不要凑数，宁缺毋滥
- 数据类素材必须含数值、口径与时间范围
输出按"观点 / 数据 / 案例"三个板块分类。
```

### 关键参数

| 参数 | 默认 | 说明 |
|------|------|------|
| {主选题} | 选题环节第 1 条 | 上游传入，不允许凭空换题 |
| {N1}/{N2}/{N3} | 3 / 2 / 2 | 不足时走失败回退，不造假凑数 |

## 摘要质量要求（写进提示词）

- **观点**：保留原作者论证逻辑，不是金句摘抄——初稿要能复用推理而不只是引用
- **数据**：数值 + 口径 + 时间范围三件套缺一不可（"90% 的人"没有口径就是废数据）
- **案例**：有主体、有动作、有结果才算完整案例

## G2 素材门禁（机器可判）

- [ ] 三个板块齐全
- [ ] 来源标注率 100%（每条都有文件名；有章节/页码的尽量有）
- [ ] 数据条数 ≥ {N2}，且每条含数值+口径+时间
- [ ] 无"弱相关凑数"：素材与选题关键词重合度由机器抽查 2 条
- [ ] 观点无整段照抄（单条引用 < 40 字为宜，长引用留给成文时的直接引用并标出处）

不达标 → 打回重跑（换检索关键词再试 1 次）→ 仍不达标 → 走失败回退。

## 失败回退

- 数据不足 2 条 → 降级为"观点 3 条 + 案例 3 个"，并在摘要顶部标注 `⚠ 数据缺口：待人工补充`
- 案例不足 → 同上标注，初稿环节会在对应小节自动留"待补案例"占位
- **缺口必须显式传递到初稿**，流水线的显式缺口比静默编造安全得多

## 版权与引用纪律（写进流水线）

- 摘要只做"可复用素材"，成文引用观点时保留出处（文末或行内标注来源名）
- 数据引用一律带出处，不搬运无法溯源的数据
- 资料库存的是"别人写的文章"，成文必须是自己的结构与表达——这是门禁 G3"AI 腔/洗稿感"检查的一部分
