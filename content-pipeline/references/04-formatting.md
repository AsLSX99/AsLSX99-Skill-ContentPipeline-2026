# 04 排版环节：1 分钟出可粘贴成品

> 产出：风格档案（style profile）+ 排版成品（HTML 预览/纯文本）+ 成品门禁 G4 的排版部分。痛点基线：挑模板约 30 分钟，自动化后 1 分钟。

## 两阶段设计（先建档案，再复用档案）

### 阶段 A：一次性建立风格档案

用户给一段**已排好版的旧文**（或口述偏好），生成 style profile 存入流水线配置：

```markdown
## Style Profile（{平台}）
- 段落：段间空一行；单段 ≤ 3 行
- 小标题：加粗，格式【一/二/三】或 emoji 前缀（记录用户实际用哪种）
- 金句：单独成行 + 加粗
- 强调：只用加粗，不用斜体/颜色
- 分隔线：有/无，样式记录
- 字号/行距：按平台默认 or 用户指定值
- 禁止：Markdown 符号残留、表格（公众号渲染差）、连续加粗超过 3 处
```

没有旧文时用默认档案（段间空行、小标题加粗、金句成行加粗、删光 Markdown 符号）。

### 阶段 B：每篇执行排版

## 参数化提示词

```
把改定稿转换成{平台}可用的排版格式，严格按 Style Profile：
段落之间空一行、小标题加粗、金句单独成行并加粗、
删除所有 Markdown 符号（#、**、-、> 等），
生成一个排版好的 HTML 页面供我预览。
输出同时给出"纯文本版"（供不支持 HTML 的编辑器粘贴）。
```

## G4 排版门禁（机器可判，针对排版部分）

- [ ] Markdown 符号残留数 = 0（正则扫描 `#+ |**|^\- ` 等）
- [ ] 段间空行符合档案
- [ ] 金句成行且加粗
- [ ] 无公众号渲染差的元素（表格、脚注、外链样式）
- [ ] HTML 预览可打开、无溢出
- [ ] 与 style profile 逐项比对一致（有旧文档案时）

## 失败回退

- HTML 生成失败 → 降级输出纯文本版 + 排版规则说明，人工粘贴后手动加粗
- 用户无风格档案 → 用默认档案并在交付时提示"可发一段旧文建立专属风格"

## 时间账

| 项 | 以前 | 现在 |
|----|------|------|
| 排版 | 30 分钟 | 1 分钟 |

## 与其他环节的接口

- 输入：03 改定稿 + 配置中的 style profile
- 输出给 05：排版成品（HTML + 纯文本）+ G4 排版部分结果
